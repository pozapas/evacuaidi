# Reported aggregate route-guidance output

`V6_PROVISIONAL_MAP_SCENARIO_ENSEMBLE_100X5.csv` contains 500 paired outputs: 100 scenarios at each of five declared uptake conditions (`C = 0.0, 0.1, 0.3, 0.5, 0.7`). The values are aggregate completion and route-target outcomes used to prepare the V6 manuscript tables and figures. No raw RFID trajectory or agent-level record is included.
